# Մանեի աշխարհը — Волшебный мир Мане

Детская 3D-игра для Мане (3–4 года): React 19 + TypeScript + Vite + Three.js (React Three Fiber).
Интерфейс и голос — на армянском. Нет рекламы, покупок, чата, регистрации и отправки данных: всё хранится в браузере устройства.

## Запуск

```bash
npm install
npm run dev
```

Проверка и сборка (папка `dist/`): `npm run build`, просмотр сборки: `npm run preview`.

## Публикация: GitHub → Vercel

Важно: сначала `git init` именно в этой папке.

```bash
git init -b main
git add .
git commit -m "Мир Мане"
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Дальше на vercel.com: **Add New → Project → Import**, настройки подхватятся из `vercel.json`. Или из папки: `npx vercel --prod`.

## Управление

Касание/мышь — всё нажимается и перетаскивается. В прогулке, машине, космосе и море: джойстик, касание места или стрелки.
🏠 — главное меню, 🔊 — повторить задание, ⭐ — комната наград, 🎵 — музыка, ⚙️ — раздел для родителей (на титульном экране и в меню).

## Структура

```
src/
  App.tsx               переходы между сценами, таймер сессии
  core/                 audio (синтез звуков и музыки), voice, store (сохранение), rewards, phrases.json
  kit/                  base (сцена, камера, частицы, Tap/Drag), people, animals, items, nature, world (ходьба/полёт), decorate
  scenes/               Home, Adventure, Kitchen, Pets, Market, Prank, Puzzles + puzzles/ (15 игр), Salon, CarCity,
                        Garden, Music, Birthday, Draw, Space, Sea, Room, Card
  ui/                   HUD, Parents (настройки, лимит времени, экран отдыха), paint
public/voice/           192 армянские фразы (.m4a)
tools/                  make_voice.py — озвучка; *.mjs — автотесты (нужны Chrome и `npx vite --port 5199 --host 127.0.0.1`)
```

## Продолжение: «Մանե, Անուլիկ և Հարություն քեռի»

Оригинальная игра сохранена полностью (все 16 сцен, Мане, голос, музыка, звуки). Добавлено:

- **Анулик (15 лет)** — новая 3D-героиня из того же набора деталей (`Anulik` в `src/kit/people.tsx`), 5 образов гардероба.
- **Выбор героя и режимы** (`who`): Мане, Анулик, Харутюн, семейные приключения, вдвоём на одном устройстве.
- **Хабы-карусели** в стиле оригинала: игры Анулик (20), игры Харутюна, приключения (12), занятия сестёр (10), режим вдвоём, новые игры Мане.
- **Открытый 3D-город** (`city`): 16 мест с жителями, предметами и секретами, комнаты сестёр, тайная комната, полянка феи; машина Харутюна, автобус по карте, смена дня и ночи, погода, неожиданные события.
- **Сказки Харутюна** (`tales`) и **смартфон Анулик** (`phone`): альбом, камера, гардероб, карта путешествий, задания дня, награды.
- Механики мини-игр перенесены из 2D-версии (ветка `2d-version`) в `src/legacy/` и показываются панелью поверх 3D-сцены.
  Игры Мане, которые уже есть в оригинале (кухня, сад, музыка, салон, пазлы и т. д.), открываются в оригинальных сценах.

## Голос продолжения

Тот же синтезатор и голос, что в оригинале (Piper, `hy_AM-gor-medium`, та же обработка):
Мане и рассказчик — тон ×1.27 (как в оригинале), дядя Харутюн — ×1.0 (как его реплика `card_thanks`), Анулик — ×1.12.

```bash
python3 tools/collect_lines.py          # собрать новые реплики → src/core/lines.json (ключ → текст; префикс h_/a_/m_ = голос)
python tools/make_voice_family.py <hy_AM-gor-medium.onnx> <espeak-ng-data>   # озвучить (готовые файлы пропускаются)
SHARD=0/4 python tools/make_voice_family.py ...                                 # параллельно на 4 процессах: SHARD=0/4 … 3/4
```

Живой голос: замените `public/voice/<ключ>.m4a` записью с тем же именем — ключи и тексты в `src/core/lines.json`.

## Голос (оригинал)

Фразы записаны локальным синтезатором Piper (голос `hy_AM-gor-medium`, данные GPL-2.0), повышен тон.
Чтобы вставить живой голос, замените `public/voice/<id>.m4a` записью с тем же именем; тексты — в `src/core/phrases.json`.
Если файл не загрузился, используется системный армянский голос, а без него — мелодия и визуальная подсказка.
